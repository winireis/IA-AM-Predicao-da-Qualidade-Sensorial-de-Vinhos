# IA-AM-Predicao-da-Qualidade-Sensorial-de-Vinhos
Trabalho desenvolvido para a Pós-Gradução em Indústria 4.0. O objetivo desse trabalho é aplicar técnicas de análise de dados, aprendizado de máquina e inteligência artificial na base de dados Wine Quality Dataset para identificar a qualidade de um vinho de forma eficiente.
